# MVPoisk

Статический каталог фильмов и сериалов для GitHub Pages.

## Что есть

- поиск по названию с подсказками;
- каталог с фильтрами по типу, жанру, году и рейтингу;
- оригинальный KinoPoisk ID используется в `movie.html?id=...`;
- отдельная страница фильма с постером, фоном, рейтингами, описанием и актёрами;
- отзывы и похожие фильмы;
- кнопка «Смотреть» формирует ссылку GGpoisk из KinoPoisk ID;
- адаптивная вёрстка;
- sessionStorage-кэш запросов на 10 минут для экономии лимита API.

## GitHub Pages

Загрузите содержимое этой папки в корень отдельного репозитория. В GitHub откройте:

`Settings → Pages → Deploy from a branch → main / (root)`

После публикации сайт работает без npm и сборки.

## Конфигурация

`js/config.js` содержит:

- `API_BASE` — API ПоискКино;
- `API_KEY` — токен;
- `GGPOISK_BASE` — домен просмотра;
- `SOCIAL_ALIAS` — параметр партнёрской ссылки;
- лимит карточек и TTL кэша.

Шаблон просмотра:

`https://www.ggpoisk.ru/film/{KINOPOISK_ID}/?socialAlias=MTU3OTQxNTUy`

## Важно про лимит API

Бесплатный тариф ПоискКино ограничивает количество запросов. Публичный фронтенд использует один общий токен, поэтому при большом трафике лимит может закончиться. Для продакшена при необходимости можно перейти на более высокий тариф или добавить серверный кэш.

## Изображения
Постеры, фоны и фото актёров отдаются через `wsrv.nl` как кэширующий image proxy. Это сделано потому, что прямые URL CDN Кинопоиска/Яндекса могут быть недоступны у части посетителей. Если исходная картинка не загрузилась даже через proxy, интерфейс показывает локальный fallback вместо битой картинки.


## Надёжность постеров

Изображения сначала запрашиваются через `wsrv.nl`, затем автоматически пробуются альтернативный `previewUrl` и прямые URL. Если все источники недоступны, остаётся встроенная визуальная заглушка — каталог и страница фильма продолжают работать.


## Встроенный просмотр

На странице фильма кнопка «Смотреть» лениво подключает партнёрский Kinobox-совместимый скрипт и ищет источник по оригинальному KinoPoisk ID фильма/сериала. Настройки находятся в `js/config.js`:

- `PLAYER_SCRIPT_URL` — `https://phobplay.top/kinobox.js`
- `PLAYER_BASE_URL` — `https://fbhdplay.top/`

Если партнёрский плеер не разрешит запуск с GitHub Pages или временно не ответит, под плеером остаётся резервная ссылка на GGpoisk с тем же KinoPoisk ID.
