# MVPoisk v47

- Исправлена ситуация, когда основной Rendex/Vibix создавал пустой/чёрный iframe или вообще не отвечал.
- Если основной iframe не появился за таймаут, MVPoisk автоматически ищет запасной встроенный источник.
- Если iframe пустой (`about:blank`), переключение на запасной источник происходит автоматически.
- Добавлена компактная кнопка «Запасной»; при повторном нажатии она перебирает следующий доступный источник без большого меню.
- Для запасных источников используется прямой список Kinobox, а при проблемах CORS — его SDK только как поиск источников.
- Turbo/Obrut исключены из запасной цепочки; Collaps оставлен последним приоритетом.
- GGPoisk остаётся отдельной кнопкой и окончательным внешним резервом.
- Cache-bust/PWA shell обновлены до v47.
